# 什么是Python标准库，如何导入模块

* 在软件开发中，库就像是一个工具箱
* 有了库，就无需从0开始实现代码的每一部分，库提供了预写好且可复用的代码，比如函数、类和数据结构供你使用
* Python拥有庞大的标准库，内置大量模块，它们都是已经经过标准化、充分验证的方案，用来解决程序员日常遇到的各类问题与任务，例如：

1. 和操作系统交互
2. 文件操作
3. 网络通信
4. 日期与时间处理
5. 数学运算
6. 使用正则表达式
7. 更多

* 一些常见的模块有：
* math、random、re、datetime等等

1. math用于执行复杂的数学运算
2. random用于生成随机数
3. re用于处理正则表达式
4. datetime用于处理时间和日期

## 但是要如何访问这些内置模块中定义的变量、常量、函数和类呢

* 这个时候就可以使用 **import** 语句，通过这类语句就能将模块导入到你的Python脚本中
* import语句一般写在文件的开头，同时你也可以自定义导入方式
* 基础格式：

```
import module_name
```

* 这样就导入好了，后续你想使用该模块时就可以这样写：

```
module_name.function_name()
```

* 这就是最基本的导入语句，当然还有其它的方法：
* 如果你需要使用另一个名称导入模块(也就是“别名”)，就可以这样写：

```
import module_name as module_alias #加上 as 后再在末尾写上别名
```

* 这种方法常用于缩短长模块名称，或者避免命名冲突
* 比如：如果你想在代码中用别名代指 math 模块，可以给它设置一个 m 的别名

```
import math as m
```

* 然后就可以使用该别名调用 math 模块

```
m.sqrt(36)
```

## 有时候你不需要从模块中导入所有内容，可能只需要一两个特定的函数或类

* 针对这种场景，Python也提供了相应的语法
* 这种导入语句从 **from** 开头，后面写上模块名称，接着是关键字 **import** ，最后填写想要导入的元素名称：

```
from module_name import name1, name2
```

* 之后你就可以在代码里直接使用这些名称，不需要加上模块前缀
* 如果你想给导入的名称设置别名的话，可以在每个名称后面使用 as 关键字再接上别名

```
from module_name import name1 as alias1, name2 as alias2
```

* 如果你只想从 **math** 模块导入 radians 、sin 、cos 这几个函数：

```
from math import radians, sin, cos
```

* 这样就可以直接在代码中调用这些函数，不需要写模块作为前缀

## 最后，我们来看以星号“\*”结尾的导入语句

* \* 的作用是告诉Python：导入该模块里的**全部内容**，并且调用时**不需要写模块名作为前缀**  
  ‍

```
from module_name import *
```

* 例如，当导入math模块时使用这种方法，就可以直接调用该模块内定义的任何函数，不需要加上模块名作为前缀：

```
from math import *
print(sqrt(36))  # 6.0
print(pow(5, 2)) # 25.0
print(exp(1))    # 2.718281828459045
```

* 但这种方法一般不推荐使用，因为可能会造成**命名冲突**，让代码难以分辨某些名字到底来自哪里

## 下面还有一个Python中非常重要的惯用写法

```
if __name__ == '__main__': 
    # Code
```

* **\_\_**name\_\_ 是Python中的一个特殊变量
* 当直接运行一个Python文件时，Python会把这个变量的值设为字符串"**\_\_**name\_\_"
* 如果该Python文件作为模块被导入到另一个脚本中，那么这个变量就会被设置成该模块的名字(通常是去掉 .py 后缀的文件名)
* 这就是为什么Python脚本中经常会有这个条件判断
* 里面的代码只会在脚本作为主程序直接运行时才会执行
* 如果该脚本被作为模块导入，那么代码块中的代码则不会执行
