# enumerate and zip的作用

* 在之前的学习中学了关于循环打印：

```
languages = ['Spanish', 'English', 'Russian', 'Chinese']

for language in languages:
    print(language)
"""
输出：
Spanish
English
Russian
Chinese
"""
```

* 但如果要让它追踪每个元素的索引呢
* 有一种方法是创建一个变量
* 并在每次循环是依次递增

```
languages = ['Spanish', 'English', 'Russian', 'Chinese']

index = 0

for language in languages:
    print(f'Index {index} and language {language}')
    index += 1
"""
输出：
Index 0 and language Spanish
Index 1 and language English
Index 2 and language Russian
Index 3 and language Chinese
"""
```

* 第二中方法则更加简单有效
* 就是现在要学习的 **enumerate()**
* 将列表传递给该函数，并使用该函数的返回值转换为一个列表：

```
languages = ['Spanish', 'English', 'Russian', 'Chinese']

list(enumerate(languages)) # [(0, 'Spanish'), (1, 'English'), (2, 'Russian'), (3, 'Chinese')]
```

* enumerate()中的每一个对象(现在在其中的是列表)都是一个元组
* 元组内包含了序号，在序号后的就是我们传入的元素

```
languages = ['Spanish', 'English', 'Russian', 'Chinese']

for index, language in enumerate(languages): # enumerate()取出了索引和索引对应的元素，index接收索引号
    print(f'Index {index} and language {language}')
"""
输出：
Index 0 and language Spanish
Index 1 and language English
Index 2 and language Russian
Index 3 and language Chinese
"""
```

* 这样就不用手动创建和更新变量
* 如果你需要并行遍历多个可迭代算法的话
* 我们也可以加上一个可选参数设定计数的起始值
* start (开始)：

```
languages = ['Spanish', 'English', 'Russian', 'Chinese']

for index, language in enumerate(languages, 1):
    print(f'Index {index} and language {language}')
"""
输出：
Index 1 and language Spanish
Index 2 and language English
Index 3 and language Russian
Index 4 and language Chinese
"""
```

## 那么就该使用 zip()

* 该函数能将列表组合成元素对的形式
* 并返回一个由元组构成的迭代器

```
developers = ['Naomi', 'Dario', 'Jessica', 'Tom']
ids = [1, 2, 3, 4]

list(zip(developers, ids)) #将 developers 与 ids 一一对应
 # [('Naomi', 1), ('Dario', 2), ('Jessica', 3), ('Tom', 4)]
```

* 以下是一个使用该函数与循环结合的遍历演示

```
developers = ['Naomi', 'Dario', 'Jessica', 'Tom']
ids = [1, 2, 3, 4]

for name, dev_id in zip(developers, ids): #将 developers 分配给 name，将 ids 分配给 dev_id
    print(f'Name: {name}')
    print(f'ID: {dev_id}') #分别格式化打印
"""
输出：
Name: Naomi
ID: 1
Name: Dario
ID: 2
Name: Jessica
ID: 3
Name: Tom
ID: 4
"""
```

* 上面的示例是把两个列表合并成对应的形式并返回一个元组迭代器
* 然后再循环中将每个元组拆包并分配给 name 和 dev\_id
* 最后循环打印每条语句分别输出
* 该函数结合循环可以使代码变得更加简洁
