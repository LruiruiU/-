# Python中常见的错误信息有哪些

* 在写Python代码时，我们常常会遇到一些报错
* 理解这些报错代表着什么有助于高效的调试代码
* 如果你能完全读懂报错信息，那么就能看出是哪里出现了什么错误
* 常见的报错信息有：

1. **SyntaxError** 语法错误：代码不符合Python语法，解释器读不懂
2. **NameError** 名称错误：使用了一个没有定义的变量/名字，Python不认识
3. **TypeError** 类型错误：用错了数据类型，比如拿整数去拼接字符串，拼不上
4. **IndexError** 索引错误：列表/字符串 取下标时取了不存在的下标，比如让Python在0、1、2里面找3，根本不存在
5. **AttributeError** 属性错误：调用了对象没有的方法/属性，拿一个不符合的东西去使用

## **SyntaxError 演示**

```
print("Hello, world!"
# SyntaxError: unexpected EOF while parsing
```

* 没有右括号进行闭合

## **NameError 演示**

```
print(name)
# NameError: name 'name' is not defined
```

* 没有定义name是什么

## **TypeError 演示**

```
5 + "5"
# TypeError: unsupported operand type(s) for +: 'int' and 'str'
```

* 字符串拼整数拼不上

## **IndexError 演示**

```
my_list = [1, 2, 3]
print(my_list[5])
# IndexError: list index out of range
```

* 没有 5 却要找 5 ，找不到

## **AttributeError 演示**

```
num = 42
num.append(5)
# AttributeError: 'int' object has no attribute 'append'
```

* .apend()是列表方法，无法用在整数上
