# 异常处理如何让运作

## 异常处理是什么

* 在Python中，异常处理是编写稳定、抗故障程序的核心要点，借助它，可以预判代码可能会出现的问题，并条理清晰的处理这些问题
* 简单来说，异常处理就是在程序运行过程中捕捉、管控各类运行错误的机制，能避免代码毫无征兆的崩溃

## 异常处理的代码块

* Python提供了 **try** 、**except** 、**else** 、**finally** 这几个代码块来稳妥地处理程序报错

### try 、except：

```
try:
    x = 10 / 0
except ZeroDivisionError:
    print("You can't divide by zero!")
```

* try：用来放在你认为可能会报错的代码段
* except：当 try 代码块里触发了**指定类型的报错时这段代码才会执行**
* 这种情况下，除零计算会触发 ZeroDivisionError (除零错误)，出现错误后该错误会被捕获并打印 "You can't divide by zero!"
* 当然你也可以设置多个except：

```
try:
    number = int('abc')
    result = 10 / number
except ValueError:
    print('That was not a valid number.')
except ZeroDivisionError:
    print("Can't divide by zero.")
```

* 用来捕获不同的错误

### else 、finally：

```
try:
    x = 10 / 2
except ZeroDivisionError:
    print("You can't divide by zero!")
else:
    print('Division successful:', x)
finally:
    print('This block always runs.')
```

* else：这个就与except相反，它是try代码块**没有抛出任何异常时才会执行代码**
* finally：它则是无论程序是否报错代码都会继续执行，常用于收尾工作，如关闭文件、释放资源等操作

## 还可以直接调用异常对象

* 也就是使用 as 关键词给异常对象设置别名
* 以下示例中将错误对象命名为 e ：

```
try:
    x = 1 / 0
except ZeroDivisionError as e:
    print(f'Error occurred: {e}')
```

* try代码块执行 1 / 0 是触发 ZeroDivisionError
* as将本次生成的异常实例赋值给变量e
* 执行打印语句，e会携带系统原生报错描述，控制台输出：Error occurred: ZeroDivisionError
* 用于日志记录，代码调试

### 还可以在单个except分支里使用元组一次性捕获多种异常：

```
try:
    number = int(input('Enter a number: '))
    result = 10 / number
except (ValueError, ZeroDivisionError) as e:
    print(f'Error occurred: {e}')
```
