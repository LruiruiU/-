# 什么是集合，集合有什么作用

* 集合是Python的内置数据结构之一，它的核心特性之一就是不储存重复的数值，如果你尝试给一个集合添加重复值，那么只有一个值会被储存
* 集合是可变且无序的，这意味着储存在集合内的元素没有特定的顺序，因此不能通过索引或键来访问它们
* 集合内只能包含如数字，字符串和元组等不可变的数据类型的值，此外，它们还支持数学里的集合运算：并集、交集、差集和对称集
* 想要创建一个集合很简单，只需要把元素写在大括号“{}”里，元素之间用逗号隔开：

```
my_set = {1, 2, 3, 4, 5}
```

* 使用集合有一个点很容易踩坑：

## 如果你想创建空集合，那么必须使用 set() 函数

* 如果你只写一对大括号，那么Python会把其识别为词典而非集合

```
set() # 集合
{}    # 词典
```

## 你可以使用 .add() 向集合内添加一个元素

```
my_set = {1, 2, 3, 4, 5} 
my_set.add(6) #添加6
#那么更新集合就是
my_set = {1, 2, 3, 4, 5, 6}
```

* 如果你试图给集合添加一个集合内已经存在的元素

```
my_set.add(5)
#那么集合不会改变
{1, 2, 3, 4, 5, 6}
```

## 要将元素从集合内移除的话，有两种方法： .remove() 和 .discard()

```
my_set.remove(4)
my_set.discard(4)
```

* 如果使用 .remove() 方法移除集合内不存在的元素的话，会抛出 KeyError 键错误
* 但如果是 .discard() 方法的话则不会报错

## 这个方法会移除集合中的所有元素：.clear()

```
my_set.clear()
```

## Python集合还提供了很多实用的方法用来实现常见的数学集合运算

### .issubset() 和 .issuperset() 方法分别用于判断一个集合是否是另一个集合的子集、超集

* 子集：假设b是a的子集，那么a包含b的所有元素
* 超集：刚好反过来，假设b是a的超集，那么b包含a的所有元素

```
my_set = {1, 2, 3, 4, 5}
your_set = {2, 3, 4, 6}

print(your_set.issubset(my_set)) #检查your_set是否为my_set的子集，结果为 False
print(my_set.issuperset(your_set)) #检查y_set是否为your_set的超集，结果为 False
```

### .isdisjoint() 用于判断两个集合是否**不相交(互斥)**，也就是两个集合内没有任何一个同样的元素

```
print(my_set.isdisjoint(your_set)) #因为两个集合中有相同的元素，所以 False
```

### 并集运算符“ | ”会合并多个个集合并返回一个新集合，里面包含个集合里的所有元素(自动去重)

```
my_set | your_set # {1, 2, 3, 4, 5, 6}
```

### 交集运算符“&”会合并多个个集合并返回一个新集合，只保留个集合里共有的元素

```
my_set & your_set # {2, 3, 4}
```

### 差集运算符“-”会合并多个个集合并返回一个新集合，包含第一个集合里存在，但其它集合中不存在的元素

```
my_set - your_set # {1, 5}
```

### 对称差集运算符“^”会合并多个个集合并返回一个新集合，只取集合中不重复的元素

```
my_set ^ your_set # {1, 5, 6}
```

### 这些运算符都有对应的**复合赋值运算符**，只需要在对应的运算符后面加上等号，这类运算符就会自动将运算结果赋值给表达式里的第一个集合

```
|= &= -= ^=
-----------------
my_set -= your_set
print(my_set) # {1, 5}
```

### in 运算符用于判断一个元素是否在集合中，结果是True或False

```
print(5 in my_set) # True
```
