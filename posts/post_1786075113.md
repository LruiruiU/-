# Python中常用的调试方法

* 调试时每一个Python开发者所必备的技能，理解基础可以帮助你高效识别并解决问题
* 调试是识别和解决代码中的错误或缺陷的过程，它包括检查迪马、理解流程、使用工具定位问题根源
* 接下来来看看Python中常用的调试方法

## print()和f-strings

* 在代码的不同位置使用print()和f格式化字符串可以帮你理清代码执行流程，看清各个变量实时的值

```
# 定义一个add函数，接收a、b两个参数
def add(a, b):
    result = a + b   # 把a和b相加，结果存入result变量
    # f字符串打印输出：输出“a加上b等于result”
    print(f'Adding {a} and {b} gives {result}')
    return result    # 把相加的结果返回出去
```

* 通过打印a和b的值可以验证代码是否如期运行

## 模块交互调试 pdb

```
import pdb #导入Python自带的 pdb 调试模块

def divide(a, b):
    pdb.set_trace() #断点，程序跑到这里会暂停，进入调试交互模式
    return a / b

print(divide(10, 2))
```

* 通过调用 set\_trae() 函数设置断点调试，可以逐行执行代码，查看变量取值，弄清楚程序的运行逻辑
* 运行了上面的代码后，控制台会输出你当前运行文件的路径，触发断点的代码行以及紧随其后的代码，同时弹出 pdb 交互式调试命令行窗口：

```

-> return a / b #下一行即将执行的代码是 return a / b（执行除法并返回结果）
(Pdb) #已经进入pdb 交互式调试终端，等待你输入调试指令
```

### 例如：想查看代码中当前的元素类型：whatis

```
(Pdb) whatis a
<class 'int'>
(Pdb) whatis divide
Function divide
```

* 运行就可以看到代码类型为整数

### 你想要继续执行代码的话，可以使用 continue 指令，或者它的别名：cont、c

```
(Pdb) continue
5.0
```

## IDE调试工具

* 许多集成开发环境(IDE)提供先进的调试工具，如断点、单步执行和变量查看

## 使用VS Code调试器

* 如果你使用的是VS Code，那么可以在代码中设置断点，启动调试器后程序就会在断点位置暂停运行
* 接下来以 divide 函数作为示例：

### 第一步：设置你的代码

* 创建一个名为 [main.py](http://main.py) 的文件，在里面写入

```
def divide(a, b):
    result = a / b
    return result

print(divide(10, 2))
print(divide(15, 3))
```

### 第二步：设定断点

1. 在第 2 行代码`result = a / b`左侧的边距（装订线区域）点击，即可打上断点
2. 出现红色圆点，就代表断点设置成功

### 第三步：启动调试

1. 按下快捷键**F5**，或点击菜单栏「运行 > 启动调试」
2. 弹出选项时选择「Python File（Python 文件）」
3. 调试器运行后，程序会自动暂停在你设置的断点行

### 第四步：查看变量信息

1. 鼠标悬停在变量名称上，可直接查看变量当前取值
2. 左侧「Variables（变量）」面板，能查看所有局部变量
3. 底部「Debug Console（调试控制台）」，可手动输入表达式实时计算求值

### 第五步：逐行调试代码

* **继续运行（F5）**：恢复程序执行，直到遇到下一个断点再暂停
* **单步跳过（F10）**：执行当前整行代码，直接跳到下一行，不进入该行调用的函数内部
* **单步进入（F11）**：如果当前行有函数调用，会进入函数内部逐行执行
* **单步跳出（Shift+F11）**：快速退出当前所在的函数，回到函数被调用的位置

IDE调试工具提供了一个可视化界面，用具检查程序状态，比单用打印语句更容易识别和修复问题
