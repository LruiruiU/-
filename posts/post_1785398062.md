# Lambda是什么，可以用来做什么

* 在之前的学习中
* 我们习惯的是用关键词 def 来定义函数

```
def square(num):
    return num ** 2

print(square(4)) #输出 16
```

* 但是当我们使用像map()和filer()这类**高阶函数(能接收另一个函数当参数的函数)**时
* 就可以使用**匿名内联函数(lambda)：**

```
lambda num: num ** 2
"""
lambda 创建匿名函数
前num 参数，用于接受传入的数字
: 分隔参数和执行代码
num ** 2 执行代码，进行运算
"""
```

* 匿名函数直接就可以看出来是没有名字的函数
* 所以该函数不会与名称关联
* lambda非常适合在高阶函数中使用：

```
numbers = [1, 2, 3, 4, 5]

even_numbers = list(filter(lambda x: x % 2 == 0, numbers)) #判断是不是偶数
print(even_numbers)  #输出 [2, 4]
```

* 注意不要将lambda函数赋值给变量

```
numbers = [1, 2, 3, 4, 5]

square = lambda x: x ** 2
squared_numbers = list(map(square, numbers))
print(squared_numbers) #输出  [1, 4, 9, 16, 25]
```

* 虽然这样做不会报错，代码可以正常运行
* 这种做法违背了匿名函数的初衷
* 要这样做的话为什么不这样呢

```
numbers = [1, 2, 3, 4, 5]

def square(num):
    return num ** 2

squared_numbers = list(map(square, numbers))
print(squared_numbers) #输出 [1, 4, 9, 16, 25]
```

* 除此之外，应该要避免创建难以阅读，不必要的复杂lambda函数：

```
result = (lambda x: (x**2 + 2*x - 1) if x > 0 else (x**3 - x + 4))(3)
print(result)  #输出 14
```

* 这样还会有人想看吗
* 所以当语句复杂是最好还是创建一个独立函数：

```
def calculate_expression(x):
    if x > 0:
        return x**2 + 2*x - 1
    else:
        return x**3 - x + 4

print(calculate_expression(3))  #输出 14
```

A.定义具有多行和条件逻辑的函数

B.在多个模块之间创建可重复使用的函数

C.编写一个小型函数，供 `map()` 或者 `filter()` 调用时使用

D.创建具有描述性名称的函数

2.为什么通常认为将lambda分配给变量是不好的做法

A.会导致语法错误

B.违背了匿名函数的初衷

C.lambda运行的要比普通函数慢

D.大多数版本的Python不支持这样做

3.以下使用lambda函数的缺点是什么

```
result = (lambda x: (x**2 + 2*x - 1) if x > 0 else (x**3 - x + 4))(3)
```

A.让代码更容易阅读

B.可能会导致因为模糊性而出现意想不到的行为

C.更难理解和维护

D.执行需要太多资源

(C)√
