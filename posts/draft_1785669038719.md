# 今天来做的是一个简单的网页

## 先来讲讲讲网页的构成

* 网页一般由三个主要元素构成

### 第一个就是“前端三剑客”

* 那前端是什么呢，前端就是你打开网页所有能看到的东西，这些都是前端

1. html : 网页的骨架，这个决定了网页里有什么内容功能
2. CSS : 网页美化，负责颜色排版之类的
3. JavaScript : 网页的行为，这个就是用户能在网页里做什么，能在网页里搜索、在网页里点这个有什么效果点那个有什么效果

### 第二个就是后端

* 后端就是用来处理业务逻辑的，登录、修改个人简介、修改个人头像、切换账号等等
* 后端语言主要有 Java、php、python等等，现在最主流的还是Java
* 注意:网页的后端代码我们是一定看不到的，如果你能看到别人网页的后端代码的话那你就可以去交src领赏金了(

### 最后一个就是数据库了

* 每一个网站都有数据库，数据库是什么？数据库顾名思义就是储存数据的仓库
* 当你注册网站账号，你的账号密码就被记录到数据库中，往后你登陆的时候就凭借着记录的账号密码来识别你输入的账号密码是否正确
* 所以数据库是十分重要的，里面记录的账号数据是十分庞大的，数据库是否安全关系到用户的账户是否安全

## 网页构成讲完了现在就该上手试试了

* 虽然用记事本也可以写，但有好用的工具为什么不用呢

* 主要:创建文件的时候后缀一定是 .html 不然你怎么写都是没用的

### 先来讲一讲html文件的基础结构

```
<!DOCTYPE html>
    <html lang="en">
        <head>
            <meta charset="UTF-8"> 
            <title>Title</title> 
        </head>
        <body>

        </body>
    </html>
```

* 这个就是html文件最基础的结构了，PhpStorrm是一创建好html文件就自带的，Trae只需要打出一个“<”按Tab，接着按下回车再按Tab就能补全

```
<!DOCTYPE html>
    <html lang="en">
        <head>
            <meta charset="UTF-8">
            <meta name="viewport" content="width=device-width, initial-scale=1.0">
            <title>Document</title>
        </head>
        <body>
            <h1>hello world</h1>
        </body>
    </html>
```

* 这个是Trae自动补全的，它这个是自动写了一个 hello world，差别也不大
* 在上面的代码中，有很多都是被“<>”括起来的
* 这个叫做标签，标签是html文件必须的一部分
* 从如果是正规写的标签从标签名就能看出里面写的是什么类型的东西
* 有些标签是“<>”这样的，有些标签是“</>”这样的，这两个的区别就是没有“/”的标签是**开始标签**，有“/”的则是**结束标签**
* 在html中绝大多数的标签都是**成对出现**的，是有头有尾的
* 但也有少数的标签是**单个出现**，比如上面代码的<meta charset>
* 在上方代码中，有一种标签内写着“\*\*\*=\*\*\*”这个就代表着**标签的属性**，每一个属性都有着一个作用
* 比如：

```
<html lang="en">
<meta charset="UTF-8">
#在下面会讲这些是什么意思
```

* 那么html的最基础结构为什么叫最基础结构呢
* 让我们来看看这里面写的是什么意思：

```
<!DOCTYPE html>
<!--这个是 文档的类型声明 ，告诉浏览器这个文档是html类型的，这个是硬性规定，不可更改-->
    <html lang="en">
<!--这个意思是 浏览器页面语言 ，en就是英文-->
        <head>
<!--这个就是 头部标签，里面可以设置网页标题，编码格式等-->
            <meta charset="UTF-8"> 
<!--这个是 UTF-8 编码字符集，是全球最通用的字符集，如果没有特殊要求那就是用它，字符集类似于电报，别人用一种格式发的电报你需要使用相同的格式进行解读才能知道对方发的是什么-->
            <title>Title</title> 
<!--这里面是设置网页标题的-->
        </head>
        <body>
<!--这个就是网页的身体，也就是内容标签，里面写的是网页会显现出什么内容-->

        </body>
    </html>
--------------------------------------------------------------------------------------------------------------
PS:你应该已经注意到了，我在这里面写的注释不像之前那样用“#”，而是用“<!-- -->”，这是因为“#”是Python里的注释方式，每个编程语言都有自己的注释方式的，html的注释方式就是使用“<!-- -->”，当然这个不用你自己手动打
在PhpStorrm中使用“ctel+/”就可以快捷注释
在Trae中则是“ctrl+k”后再按“ctrl+c”
如果你要取消注释那么再按一边就行了
对于初学者来说多些注释是一种好习惯，可以加深自己的印象，也可以提示自己这里写的是什么
```

### 接下来我们来看看除了这些标签意外还有哪些网页的常见标签

* 因为网页标签实在太多了所以就只看看最常用的那些：

```
1.标题标签
标题标签有六个等级
<h1></h1> 一级标签
<h2></h2> 二级标签
<h3></h3> 三级标签
往下类推一共六级
随着级别下降字体会逐渐减小
注意：标签一般都是小写的，除了文档类型声明
2.段落标签
<p></p>
这里面写的就是每一个段落里面的文字
3.换行标签



若果你想让你写的文字进行换行，就要使用这个：
<p>第一行 


   第二行 


   第三行 


</p>
注意：

标签是单个出现的，不需要</br>进行结尾
4.分割标签
<hr>
顾名思义此标签的作用是创建一个分割线，它也是单独出现的
5.div标签
<div></div>
此标签是用在CSS布局中的
6.span标签
<p>这是一个<span>文字</span></p>
此标签主要用来更好的选中文字，方便后续进行上色等操作
7.图片标签
<img src="" alt="">
自动补全该标签时会自动带上两个属性
* src=""中写的是图片的地址，地址有两种，一种是本地地址，一种是在线地址
* 本地地址就是该图片在你电脑中的图片，主要：如果要载入本地图片的话该图片是要和你编写的html文件在同一级目录下的，否则无法识别，当图片和html文件在同一目录下后，src="./"这样写编辑器就会自动提示出图片名称，选择就好，如果没有提示的话那就说明图片和html文件不在同一级目录下
* 在线地址就是网上能直接搜所看到的图片，在浏览器上找到你想载入的图片，右击该图片，选项中有一个“复制图片地址”点击该选项然后把复制的地址粘贴到src=""中就行了，如果在你写的网页里出现无法显示在线图片的话，这个是正常的，因为有些网站的链接会做一个“版权保护”遇到这种情况就只能换一张了
$ alt=""中写的是如果你载入的图片不存在，或者损坏了，那么就会显示alt=""中写入的文字
8.超链接标签
<a href=""></a>
超链接就是那种你点一下，就会跳转到别的地方的链接，href=""中写的就是你要跳转到的地址，两个标签中间写的则是跳转的媒介，比如：
<a href="https://www.baidu.com/">跳转百度</a>
这样就会在网页上生成一个“跳转百度”的文字，点一下就会跳转到百度首页了，但这样跳转会直接覆盖掉你当前的网页，如果你想让它新开一个网页而不是覆盖当前网页的话，那么可以新加一个 target=""属性，表示以什么方式打开
<a href="https://www.baidu.com/" target="_blank">跳转百度</a>
_blank就是新开一个网页打开
9.列表标签
列表标签有两种
第一种是有序列表
<ol>
    <li></li> <!--这个标签叫做列表项，也就是你这个列表里有什么东西，会自动在列表项前面加上有序的编号-->
</ol>
第二种是无序列表
<ul>
    <li><li> <!--相比于有序列表，无序列表并不是你写进去的东西会没有顺序的乱排，而是它前面不会带编号，而是以“·”符号作为标记
</ul>
10.表单标签
该标签用于收集用户输入的数据，比如你的账号密码和手机号等
<form action="">
    账号：<input type="text"> <!--这个写法是“单行文本输入框”在网页上就会使 账号：(输入框) -->
    密码：<input type="password"> <!--这个就是“密码类型的输入框”在该输入框里输入的东西都会被隐藏为黑点-->
    性别：<input type="radio">男 <input type="radio">女 <input type="radio">私密 <!--这个就是性别选择了，但是这样写的                 话会导致三个选项全都可以勾选，如果想让它做到只能勾选一个选项，也就是让选项互斥的话，那么就可以加上<input type="radio" name=""> 属性，给每个选项取一个相同的名字，这样这些选项就会被归类为一组，只可以勾选其中一个，制作成一个“单选框”-->
    性别：<input type="radio" name="1">男 <input type="radio" name="1">女 <input type="radio" name="1">私密
         <!--这里面是随便你些什么都行的，只要写的是一样的就行-->
    爱好：<input type="checkbox"> <!--这个是“多选框”-->
         <button>提交</button> <!--这个就是“按钮”最上方 action=""属性内写的就是提交到的地址，但鉴于我们还没有后端，所以暂时还做不到-->
</form>
```

### 那么初始结构讲完了，现在来说说这个该怎么运行

* 运行方式有二：

1. 在电脑中找到该文件并双击运行，这是最通用的方法，使用这个方法需要先将文件“ctrl+s”保存网页，然后文件才会更新
2. 还有就是 **PhpStorrm** 中自带的“内置预览”方法：**PhpStorrm**右上方会有三个或四个图标，这个就是自带的预览方法，区别是启动的浏览器不同，电脑中有哪个选哪个，如果都没有，那就选第一个内置浏览器，这个方法是实时刷新的，不需要保存也可以显示，但我们写代码还是要养成勤保存的习惯，没准哪一天就突然出了点事导致你还没保持代码就没了呢，那就很绝望了
