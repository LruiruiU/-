# 先来讲讲讲网页的构成

* 网页一般由三个主要元素构成

## 第一个就是“前端三剑客”

* 那前端是什么呢，前端就是你打开网页所有能看到的东西，这些都是前端
* html : 网页的骨架，这个决定了网页里有什么内容功能
* CSS : 网页美化，负责颜色排版之类的
* JavaScript : 网页的行为，这个就是用户能在网页里做什么，能在网页里搜索、在网页里点这个有什么效果点那个有什么效果

## 第二个就是后端

* 后端就是用来处理业务逻辑的，登录、修改个人简介、修改个人头像、切换账号等等
* 后端语言主要有 Java、php、python等等，现在最主流的还是Java
* 注意:网页的后端代码我们是一定看不到的，如果你能看到别人网页的后端代码的话那你就可以去交src领赏金了(

## 最后一个就是数据库了

* 每一个网站都有数据库，数据库是什么？数据库顾名思义就是储存数据的仓库
* 当你注册网站账号，你的账号密码就被记录到数据库中，往后你登陆的时候就凭借着记录的账号密码来识别你输入的账号密码是否正确
* 所以数据库是十分重要的，里面记录的账号数据是十分庞大的，数据库是否安全关系到用户的账户是否安全

# HTML看完了，现在就开始看CSS啦

## ‍什么是CSS

* CSS就是一组样式设置的规则，用于控制页面的外观样式

## 为什么使用CSS

* 实现内容与样式的分离，便于团队开发
* 样式可以复用，便于网站后续维护
* 让页面更加精美

## CSS的作用

* 页面外观美化
* 布局和定位

## CSS的应用方式

* 也称为CSS引用方式，共有三种：
* 内部样式
* 行内样式
* 外部样式

### 内部样式：

* 在 title 标签下面创建一个 style 标签，在其中写入 css 代码：

```
<head>
    <!--网页采用utf-8编码格式-->
    <meta charset="UTF-8">
    <!--网页标题-->
    <title>自我介绍</title>
    <style>
       <!--在其中写css代码-->
    </style>
</head>
```

* 优点：在同一页面内部便于复用和维护
* 缺点：在不同页面之间的可重用性不高

### 行内样式

* 也称为嵌入样式，使用 HTML 标签的 style 属性定义
* 只对设置 style 属性的标签起作用

```
<div style="在这里面写css代码"><div>
```

* 优点：方便，直观
* 缺点：只对当前标签生效，缺乏可重用性

### 外部样式

* 使用单独的css文件定义，在页面中使用link标签引入

```
<head>
    <!--网页采用utf-8编码格式-->
    <meta charset="UTF-8">
    <!--网页标题-->
    <title>自我介绍</title>
    <!--引入css文件-->
    <link rel="stylesheet" href="index.css">
</head>
```

* 优点：使css样式与html页面分离，便于整个页面系统的规划和维护，可重用性高
* 缺点：由于css代码是分离到单独的css文件中的，容易出现css代码过于集中，若维护不当可能造成混乱

## 样式看完了，现在来看看选择器

* 选择器是用来选择标签的，选出来以后给标签添加样式

### 标签选择器

* 也被称为元素选择器，使用HTML标签作为选择器的名称
* 根据标签来选择标签，**以标签名开头**，主要，后面只能是花括号这种选择器影响范围大，一般用来做一些通用的设置：

```
<style>
  div{
      color: red;
    }
</style>
<body>
  <!--这个标签就会变为红色-->
  <div>我是div标签</div>
  <!--这个标签也会变为红色-->
  <div>我是div标签</div>
</body>
```

* 对往下所有的标签都生效，一般作用于通用设置

### 类选择器

* 如果你想两个标签两个颜色的话，就可以使用类选择器
* 类选择器使用自定义名称，以“.”符号作为前缀，然后再通过HTML标签的 class 属性调用类选择器：

```
<style>
  <!--class="name" 就是红色-->
  .name{
     color: red;
    }
  <!--class="sex" 就是橘色-->
  .sex{
     color: orangered;
    }
</style>
<body>
  <div class="name">我是div标签</div>
  <div class="name">我是div标签</div>
  <div class="sex">我是div标签</div>
</body>
```

* 一个class就表示一种颜色

### id选择器

* 根据id选择标签，以 “#”开头
* 元素id名称不能重复，所有id选择器只能对应与页面上的一个元素，不能复用，所以不推荐使用id选择器

```
<meta charset="UTF-8">
  <style>
    <!--myid=pink-->
    #myid{
      color: pink;
    }
  </style>
</head>
<body>
  <div id="myid">我是一个div</div>
  <!-- 注意点：虽然给其他标签设置id="box"也可以设置样式，但是不推荐这样做，因为id是唯一的，以后js通过id只能获取一个唯一的标签对象-->
  <div id="myid">我是一个新的div</div>
</body>
</html>
```

* id>class>标签

## CSS元素溢出

* 什么是css元素溢出
* css元素溢出就是当元素(标签)的尺寸超过父元素(标签)的尺寸
* 此时需要设置父元素显示溢出的子元素的方式，设置的方式是通过**overflow**属性来完成的

**---属性-------含义-----------------------------------------------------------------说明------------------------------------------------------------------------**

overflow--元素溢出--visidle默认值，显示子标签溢出部分、hidden隐藏子标签溢出部分、auto如果子标签溢出则可以滚动查看剩余部分

```
<!DOCTYPE html>
<html lang="en">

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
      .box1{
        width: 100px;
        height: 100px;
        background-color: red;
        overflow: auto;
      }
      .box2{
        width: 200px;
        height: 50px;
        background-color: green;
      }
  </style>
</head>


<body>
  <div class="box1">
    <div class="box2">子标签</div>
  </div>
</body>

</html>
```

* 子标签比父标签大就会造成元素溢出

# CSS基础讲完了，现在来讲一讲CSS布局

## 定位(position)

* 定位顾名思义就是将盒子定位到某一个位置
* 所以定位也就是在摆放盒子，按照定位的方式移动盒子

**定位模式：**

**---值----------------语义**

relative-------相对定位

absolute-------绝对定位

fixed----------固定定位

### 相对定位(relative)

* 特点：
* 元素在移动位置时，按照相对于原本位置来移动，也就是移动参照物是自己原本的位置
* 哪怕元素已经移动，但原本的位置还是被它占着的
* 位置：
* top：距离上面
* bottom：距离下面
* left：距离左面
* right：距离右面

```
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <style>
    /* 绿色盒子：开启相对定位 */
    .box1 {
      width: 200px;
      height: 200px;
      background-color: palegreen;
      position: relative;
      /* 以自身原始位置为基准：向下偏移100px、向右偏移100px */
      top: 100px;
      left: 100px;
    }
    /* 红色盒子：普通文档流元素，无定位 */
    .box2 {
      width: 200px;
      height: 200px;
      background-color: red;

* 循环就是重复做一件事
* 在编写代码的过程中，我们经常需要反复执行一些操作，例如遍历一些数据，重复输出某个字符串等
* 如果要人一次次手动执行就太慢太麻烦了，所以，对于这种重复操作，我们就可以使用循环解决

### for循环

**普通for循环：**

```
for (语句1;语句2;语句3) {
      被执行的代码块
    }
```

```
for (let i = 0; i < 5; i++) {
      console.log(i);
    }
//for(初始化; 条件; 自增){循环体}
```

* let i = 0 -->初始化，只执行一次
* 条件判断 i < 5 ,条件为Ture，执行大括号

**根据数组循环：**

```
for (let 变量名 of 数组){
    被执行的代码块
}
```

```
  <script>
    // 除了写法的区别 逻辑都是一样的
    let arr = [1,2,3,4,5,6]//数组名字叫arr
    //for来遍历 关键词后面总会接上一个括号 都是来写逻辑
    for(let item of arr){
      // 只需要打印item就可以获取对象arr的值
      console.log(item);
    }
  </script>
```

**根据object对象循环：**

```
for (let 变量名 in 对象){

}
```

```
    <script>
        let a = {
            name:"琉璃",
            age:19,
        }
        // 使用for...in...遍历对象
        for (let i in a){
            console.log(i);
            // console.log(a.i);
            // 它会默认从对象a里面找i键值对
            // 注意 如果要拿对象里面的值必须使用 对象[] 记住就行
            console.log(a[i]);
        }
    </script>
```

### while循环

适合根据条件循环

* 条件成立无限循环
* 条件不成立停止循环

```
while(条件){
    执行代码
}
```

```
let a = 10
while(a == 10){
    console.log('因为a等于10 满足条件 代码一直执行，就形成死循环');
}
```

结束死循环：

```
    <script>
        let a = 0
        // 是在网页中写while会占用浏览器内存 无限循环 导致浏览器卡死
        while (a < 10) {//判断a==10
            console.log("无限循环")
            // 我们也可通过条件来终止循环 
            a++  //a++ 每次循环 a都会加1 累加
        }
    </script>
```

**break与continue：**

* break：结束循环，运行循环外的后续代码
* continue：结束当前循环，进入下一轮循环

```
// break
        let a = [1,2,3,4]
        for (let i of a){
            // 当i为3时
            if (i==3){
                // break退出整个循环
                break
            }
            console.log(i);
        }
// continue
        let a = [1,2,3,4]
        for (let i of a){
            // 当i为3时
            if (i==3){
                // break退出整个循环
                continue
            }
            console.log(i);
        }
```

## 形参与实参

### 形参(形式参数)

* 形参说白了就是一个占位符，没有任何真实的值就是在那占着位置等待参数传入：

```
function add(a, b){
       Return a + b;
}
```

* 其中 a 和 b 就是形参

### 实参(实际参数)

* 实参也就是我们所传入的参数了，是真实的数据/变量

```
function add(a, b){
       Return a + b;
}
add(5, 6);
//输出11
```

* 其中 5 和 6 就是实参

            }else{
                start.innerHTML--
            } //通过取 innerHTML 键，让点击减号让 start 自减 -1，并且做个限制，最少购买1件
        })

# 之前讲的都是前端的东西，现在进入一个中转站：AXIOS

## AXIOS是什么

* axios是一个基于 Promise 的HTTP请求库，专门用来在浏览器 /Node.js 环境发送 GET ，POST 等网络请求，用来和后端接口拿数据，提交数据，是前端最常用的用来调用后端接口的网络请求工具

## 使用场景

* 通常用于网络请求的交互，它适用于前端和后端开发，并在许多不同的项目中均有应用
* 想要实现交互就需要双方都遵循同一套协议： http/https 协议

## 引入方式

### 通过axios本地包导入

```
<script src="axios.js"></script>
```

* 就是将axios的js文件下载到本地，然后通过 script 标签引入，页面就会得到全局变量 axios

### 通过在线地址导入

```
<script src="https://unpkg.com/axios/dist/axios.min.js"></script>
```

* 无需下载到本地，页面就会挂载全局 axios 对象，推荐使用这种方法，方便

## 接口

* 接口：API(Application Programming Interface)是指应用程序接口，定义了二u安检系统或应用程序提供的功能和服务的一组规范
* API可以允许不同的软件系统、应用程序之间进行交互和通信
* 通过API开发人员可以访问特定软件系统或服务的功能，并在自己的应用程序中集成或利用这些功能，而无需了解其内部的实现细节
* 后端负责提供接口，前端负责调用接口

‍

**参数**----------**作用**

method-----请求方式

url-------------请求地址

data-----------post请求发送数据

params-------get请求发送数据

then-----------回调函数，获取请求回来的数据

### 请求方式：

GET请求：通常用于向服务端获取数据

* 特点：请求过程中携带的参数会放在URL(网址)中显示

POST请求：通常用于向服务端提交数据

* 特点：请求过程中携带的参数会放在请求体中，不会放在URL(网址)中显示

**如果想深入了解更多，可以前往**[官方中文网站查看](https://www.axios-http.cn/docs/api_intro)

## ‍前后端交互逻辑

* 前端通过接口向后端发送请求
* 后端收到请求就会将内容响应给前端
* 前端收到响应内容再将数据进行处理
* 最后显示在页面上给用户查看

**‍了解了这些后，我们来做三个实例：**

## 查询用户，添加用户与删除用户

## 查询用户：

```
<head>
  <meta charset="UTF-8">
  <title>查询用户</title>
  //使用在线引入，使用 axios 工具
  <script src="https://unpkg.com/axios/dist/axios.min.js"></script> //这里面就是官方在线地址
</head> 
<body>
  //先弄一个按钮功能点，点击查询
  <button class = "button">查询用户</button>
  <script>
  let btn = document.querySelector(".button")
  btn.addEventListener("click",function(){ //给按钮绑定一个点击事件，点按钮就会执行其中的代码
  //使用 axios() 函数使用导入的 axios 包，里面需要写上配置项
  axios({
    url:"http://43.136.104.16:3002/chaxun",  //里面填写你要访问的接口地址，这个地址里就装着用户信息
    method:"get", //请求方法是 GET 二者的请求方法必须一样，否则接不上
  // .then() 表示请求成功后会做什么
  }).then(function(res.data){ //function 为回调函数，不明白的话可以往上再看看 事件结果 章节
  // res 为函数自带的形参，里面存的是对象类型，我们需要的是其中 data 键，值的内容是一个数组，里面装着我们需要取出的用户数据
  for (let i of res.data){ // 只用 for 对数组进行循环，每循环一次取出数组中的一个对象存放到变量 i 中
    //先使用 console.dir(i) 打印至控制台查看有哪些数据
    console.log("用户id是：",i.id,"用户名是：",i.name,"用户年龄是：",i.age) //再挨个打印出对应数据
    } 
   })
  })
  </script>
</body>
```

* 这样我们点击按钮就能在控制台看到用户信息了
* 或者不想再控制台看，想渲染到网页上：

```

 <head>
