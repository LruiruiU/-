# 什么是词典，词典如何使用

* 在Python中，词典是内置的数据结构，用于储存键值对的集合
* 它的工作原理非常类似真正的词典，需要搜索一个词来找到对应的含义
* Python词典中，是使用一个键来找到对应的值
* 当需要将值与一个独特的键关联起来时，就该使用词典了
* 这在需要根据键快速查找某个值以及需要表示结构化数据的情况下非常有用
* 以下是一个常见的词典形式：

```
dictionary = {
    key1: value1, #valuel与key1绑定
    key2: value2  #value2于key2绑定
}
```

* 要使用词典首先就要找到存放词典的变量
* 虽然不一定需要把词典赋值给某个变量，但这么做非常常见，因为这有助于将词典保存于内存中，以便日后再代码中使用
* 词典一定是在花括号(有时也叫大括号)内的，在花括号内部包含了键值对
* 每一个键都关联着一个值，所以你可以使用键访问对应的值
* 每一个值(除了最后一个)后面都要有逗号以区别不同的键值对
* 键必须在词典中是唯一且不可变的数据类型，但与之相反，值是可以重复，并且可以是任意类型的
* 以下示例储存了关于玛格丽特披萨的食谱信息：

```
pizza = {                                  #该词典被赋予给变量 pizza
    'name': 'Margherita Pizza',            #披萨名字是 Margherita Pizza
    'price': 8.9,                          #价格是 8.9
    'calories_per_slice': 250,             #每片热量是 250
    'toppings': ['mozzarella', 'basil']    #配料是 ['mozzarella', 'basil']
}
```

## 另一种方法是使用构造函数 dict() 创建词典

* 下面是玛格丽特披萨实例的 dict() 等价写法
* 向 dict() 传入由元组组成的列表作为参数，每个元组的第一个元素是键，第二个元素是值

```
pizza = dict([('name', 'Margherita Pizza'), ('price', 8.9), ('calories_per_slice', 250), ('toppings', ['mozzarella', 'basil'])])
```

* 想要获取对应的值，可以使用 **词典变量名+方括号** 方括号内写上要查询的键

```
dictionary[key]
#调用出 'Margherita Pizza'
```

* 如果你要更新其中的一个值的话，只需要添加赋值运算符 ‘=’后在后面添加新值

```
pizza['name'] = '意大利菠萝披萨'
print(pizza['name']) #输出 '意大利菠萝披萨'
```

* 如果你要修改的键不存在于词典中的话则会创建一个新的键值对

## 还有一些实用的词典使用方式

### .get() 方法同样用于检测与键关联的值

* 但与上面方法不同的是用户可以设置一个默认值，这样一来即便键不存在也不会引发报错

```
dictionary.get(key, default)
```

* 如果键不存在的话就返回我们作为第二个参数传入的默认值
* 如果存在就返回对应值

```
pizza.get('toppings', []) # ['mozzarella', 'basil']
```

### .keys() and .values()

* .keys() 和.values() 方法会返回一个视图对象，分别包含词典里所有的键与所有的值、

```
#返回所有键
pizza.keys()
# dict_keys(['name', 'price', 'calories_per_slice'])

#返回所有值
pizza.values()
# dict_values(['Margherita Pizza', 8.9, 250])
```

* 视图对象只是查看字典内容的一种方式，无需创建数据的独立副本

### .items()

* 该方法会返回一个包含词典中所有键值对的视图对象

```
pizza.items()
print(pizza) #输出 dict_items([('name', 'Margherita Pizza'), ('price', 8.9), ('calories_per_slice', 250)])
```

### .clear()

* 该方法会从词典中移除所有键值对

```
pizza.clear()
print(pizza) #输出 {}
```

### .pop()

* 该方法会删除你传入的第一个参数对应的键值对并返回这个键对应的值
* 如果该键不存在，就返回你传入的第二个参数(默认值)
* 要是键不存在，同时你也没设置默认值，程序就会抛出 **KeyError (键不存在错误)**

```
pizza.pop('price', 10) 
"""
删除掉'price'并返回8.9
若将'price'修改成不存在的键，则返回10
若键不存在，也没有设置默认值，则 KeyError
"""
```

### .popintem()

* 该函数存在于Python3.7及更早版本
* 用于移除最近插入的项目

```
pizza.popitem()
```

### .update()

* 该函数会用传入的数据批量更新词典
* 如果词典里存在相同的键，词典里旧的值会被覆盖掉

```
pizza.update({ 'price': 15, 'total_time': 25 })
```

* 这是修改后的词典

```
{
    'name': 'Margherita Pizza', 
    'price': 15, 
    'calories_per_slice': 250, 
    'toppings': ['mozzarella', 'basil'], 
    'total_time': 25
}
```
