# 循环遍历词典的常见操作

* 如果你想遍历词典、处理键值对的话，那么就可以直接使用循环
* 比如下面这个词典：

```
products = {
    'Laptop': 990,
    'Smartphone': 600,
    'Tablet': 250,
    'Headphones': 70,
}
```

* 如果想让所有产品都有20%折扣的话，那么就可以循环所有的关键值并对其价格进行调整
* **.values()**、.**keys()**、**.items()** 在这方面都经常使用
* 它们会返回一个视图对象，分别对应词典里的值、键和键值对，你可以直接把这些视图对象扔进循环里挨个遍历

### 如果你想遍历词典里所有的值的话，就可以用 .values：

```
for price in products.values():
    print(price)
#它就会把值逐个打印出来
"""
输出：
990
600
250
70
"""
```

### 如果你是想遍历词典里所有的键，那么跟上面的写法就一模一样，只不过把 .values() 换成了 keys()，或者遍历products本身也行

```
for product in products.keys():
    print(product)

# Or

for product in products:
    print(product)
#它就会把键逐个打印出来
"""
输出：
Laptop
Smartphone
Tablet
Headphones
"""
```

### 如果你需要同时变例键和值，那么就该使用 .items() :

```
for product in products.items():
    print(product)
"""
输出：
('Laptop', 990)
('Smartphone', 600)
('Tablet', 250)
('Headphones', 70)
"""
```

* 如果你想把键和值储存在不同的循环变量里，那么你可以定义它们，在这里，我们就定义了product和price两个变量，中间用逗号隔开
* 注意，顺序很重要，必须先写键再写值，千万不要搞反了

```
for product, price in products.items():
    print(product, price)
"""
输出：
Laptop 990
Smartphone 600
Tablet 250
Headphones 70
"""
```

## 现在对循环词典有了更多的了解，让我们回到最初，比如让每个价格都有20%的优惠，那就可以把每个价格都乘0.8，然后重新赋值给对应的键就行了

* 如果想要取整的话也可以将结果取整：

```
products = {
    'Laptop': 990,
    'Smartphone': 600,
    'Tablet': 250,
    'Headphones': 70,
}

for product, price in products.items():
    products[product] = round(price * 0.8)

print(products)
#输出：{'Laptop': 792, 'Smartphone': 480, 'Tablet': 200, 'Headphones': 56}
```

### 如果你想在遍历之后顺便计个数的话，就可以使用enumerate()

* 该函数相当于给每个元素自动编号，默认从0开始，当然也可以指定从几开始：

```
for product in enumerate(products):
    print(product)
"""
输出：
(0, 'Laptop')
(1, 'Smartphone')
(2, 'Tablet')
(3, 'Headphones')
"""
```

* 如果你需要，可以把这些值分配给不同的变量：

```
for index, product in enumerate(products):
    print(index, product)
```

### 如果要遍历这些值，可以使用 .values() :

```
for price in enumerate(products.values()):
    print(price)
"""
输出：
(0, 990)
(1, 600)
(2, 250)
(3, 70)
"""
```

* 也可以把它们分配给不同的循环变量：

```
for index, price in enumerate(products.values()):
    print(index, price)
"""
输出：
0 990
1 600
2 250
3 70
"""
```

### 使用 .items() 就可以得到除了索引或计数器之外的整个键值对：

```
for index, product in enumerate(products.items()):
    print(index, product)
"""
输出：
0 ('Laptop', 990)
1 ('Smartphone', 600)
2 ('Tablet', 250)
3 ('Headphones', 70)
"""
```

* 如果要自定义计数起始值的话，给 enumerate() 传入第二个参数就行
* 以下是从1开始计数：

```
for index, product in enumerate(products.items(), 1):
    print(index, product)
"""
输出：
1 ('Laptop', 990)
2 ('Smartphone', 600)
3 ('Tablet', 250)
4 ('Headphones', 70)
"""
```
