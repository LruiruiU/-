# 什么是range，该如何使用

* 该函数用于生成整数序列：

```
range(start, stop, step)
    #  开始   停止   步进
```

* 它所需要的参数是一个整合数
* 用来表示生成的数字序列的结束点：

```
for mun in range(3):
    print(mun)
"""
输出：
0
1
2
"""
```

* 如果只指定了一个参数那么就会默认从0开始
* 下面是1-4的整数序列(不包含结尾)：

```
for mun in range(1,5):
    print(mun)
"""
输出：
1
2
3
4
"""
```

* 默认情况下，整数序列是以+1递增的形式排列的
* 如果你不希望这样的话，那么可以：

```
for num in range(2, 11, 2):
    print(num)
"""
输出：
2
4
6
8
100
"""
```

* 该函数是至少要指定一个 stop 结束参数的
* 如果你不指定任何参数的话
* 那么你就会获得一个类型错误 TypeError

```
for num in range():
    print(num)
ERROR!
Traceback (most recent call last):
  File "<main.py>", line 1, in <module>
TypeError: range expected at least 1 argument, got 0
```

* 而且啊而且
* 参数只能是整数
* 如果你使用小数的话
* 那么

```
for num in range(6.6):
    print(num)
ERROR!
Traceback (most recent call last):
  File "<main.py>", line 1, in <module>
TypeError: 'float' object cannot be interpreted as an integer
```

* 如果你想生成降序的序列的话

```
for num in range(40, 0, -10):
    print(num)
"""
输出：
40
30
20
10
"""
```

* 它还可以和构造函数一起创建整数列表

```
numbers = list(range(2, 11, 2))
print(numbers) #输出 [2, 4, 6, 8, 10]
```
