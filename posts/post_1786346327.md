# raise语句的作用

* 在Python中，raise语句是一项强大的工具
* 可以用它在代码中手动触发异常
* 它能让你控制异常产生的时机与方式，以此来定义触发条件，并约束程序执行的特定运行逻辑
* **raise语句可以在程序运行的任意位置主动抛出异常，用来提示程序出现了错误或是某些预设的条件并未满足**

## 该语句有很多种触发异常的用法，最基础的就是抛出内置形异常，或是显示错误信息

```
def check_age(age):
    if age < 0:
        raise ValueError('Age cannot be negative')
    return age

try:
    check_age(-5)
except ValueError as e:
    print(f'Error: {e}') # 输出：Error: Age cannot be negative
```

* 这段代码raise就是用于主动触发异常的关键字
* 以上示例中，当传入无效的负数年龄时，就会主动抛出 ValueError (值异常) 并附带自定义的报错信息

## 还有一个用法就是重新抛出当前已捕获的异常

* 这个特性在异常处理流程里非常实用：

```
def process_data(data):
    try:
        result = int(data)
        return result * 2
    except ValueError:
        print('Logging: Invalid data received')
        raise  # 重新抛出原本的ValueError

try:
    process_data('abc')
except ValueError:
    print('Handled at higher level')
```

* 不带参数的 raise 关键词就会把当前正在处理的同一个异常再次向外抛出
* 这种写法的优势：你可以在当前层级完成日志记录，资源清理操作，同时让错误继续沿着调用栈向上传递给上层逻辑处理

## 也可以自定义异常类，来抛出专属的自定义异常：

```
# 自定义余额不足异常，继承自基础Exception类
class InsufficientFundsError(Exception):
    def __init__(self, balance, amount):
        self.balance = balance
        self.amount = amount
        super().__init__(f'Insufficient funds: ${balance} available, ${amount} withdrawn')

# 取款业务函数
def withdraw(balance, amount):
    if amount > balance:
        raise InsufficientFundsError(balance, amount)
    return balance - amount

try:
    new_balance = withdraw(100, 150)
except InsufficientFundsError as e:
    print(f'Transaction failed: {e}')
```

## raise还可以搭配from关键词实现拼接抛出，清理展示不同错误之间的关联

* 核心语法为：raise……from

```
def parse_config(filename): #parse_config用于读取配置文件并把文件内容转为整数，分两类异常做分层包装
    try:
        with open(filename, 'r') as file:
            data = file.read()
            return int(data)
    except FileNotFoundError:
        # from None：屏蔽原始底层异常，只向外抛出新异常
        raise ValueError('Configuration file is missing') from None
    except ValueError as e:
        # from e：保留原始异常链路，标记新异常由e触发
        raise ValueError('Invalid configuration format') from e

config = parse_config('config.txt')
```

### raise……from None：压制原始上下文异常

* 作用：彻底隐藏底层原始报错信息，只展示你主动抛出的新业务异常，不会附带底层溯源链路。 对应截图报错示例

```
Traceback (most recent call last):
  File "main.py", line 12, in <module>
    config = parse_config('config.txt')
  File "main.py", line 7, in parse_config
    raise ValueError('Configuration file is missing') from None
ValueError: Configuration file is missing
```

* 日志里完全看不到最初的FileNotFoundError，对外只暴露友好业务提示，适合生产环境屏蔽底层技术细节

### raise……from e：链式关联新旧异常，保留完整错误轨迹

* 作用：把新抛出的业务异常和原始底层异常绑定，日志会分段展示根因异常 + 业务包装异常，清晰溯源问题源头。 对应截图报错结构

## 你也可以assert语句按条件抛出异常，它本质上就是raise搭配AssertionError的简写

```
def calculate_square_root(number):
    assert number >= 0, 'Cannot calculate square root of negative number'
    return number ** 0.5

try:
    result = calculate_square_root(-4)
except AssertionError as e:
    print(f'Assertion failed: {e}')
```
